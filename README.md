## Featured Projects

### [Intelligent Support Ticket RAG System](https://github.com/awanishsingh123/intelligent-support-ticket-rag)

An AI-powered support application that classifies incoming tickets, retrieves relevant knowledge-base information, and generates responses grounded in the retrieved context.

**Key highlights**
- Classifies support tickets using **SVM and TF-IDF**.
- Assigns ticket priority using configurable keyword-based rules.
- Combines **Pinecone semantic search** with **BM25 keyword retrieval** in a hybrid retrieval pipeline.
- Uses **Cohere Rerank** to improve the relevance of retrieved context.
- Generates context-aware responses using **Groq-hosted LLMs**.
- Uses **PostgreSQL**, a **FastAPI backend**, and a **React frontend**.
- Includes Azure infrastructure templates.

**Tech Stack:** Python, FastAPI, React, PostgreSQL, Scikit-learn, TF-IDF, SVM, LangChain, Pinecone, BM25, Ollama, Cohere, Groq, Azure, Bicep.

### [AI-Powered Fake News Detection using NLP, Machine Learning & RAG](https://github.com/awanishsingh123/AI-Powered-Fake-News-Detection-with-DL-and-RAG)

A research-oriented project exploring fake-news analysis through traditional NLP and machine-learning classification alongside a retrieval-augmented generation workflow.

**Key highlights**
- Performs text preprocessing, NLP feature extraction, and fact-related feature analysis.
- Explores **Logistic Regression** and **Random Forest** for fake-news classification.
- Combines an NLP classification workflow with a **RAG and LLM pipeline**.

**Tech Stack:** Python, NLP, Scikit-learn, Logistic Regression, Random Forest, Pandas, NumPy, RAG, LLMs, FLAN-T5, Joblib.
