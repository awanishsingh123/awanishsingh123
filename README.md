## Featured Projects

### [Intelligent Support Ticket RAG System](https://github.com/awanishsingh123/intelligent-support-ticket-rag)

An AI-powered customer support application that classifies incoming support questions, retrieves relevant knowledge-base information, and generates context-grounded responses.

**Highlights**
- Classifies support tickets using an **SVM model with TF-IDF features**.
- Assigns ticket priority using configurable keyword-based rules.
- Combines **Pinecone semantic search** and **BM25 keyword retrieval** through a hybrid retrieval pipeline.
- Uses **Cohere Rerank** to improve the relevance of retrieved context.
- Generates context-aware responses using **Groq-hosted LLMs**.
- Stores user and support-query records in **PostgreSQL**.
- Includes a **React frontend**, **FastAPI backend**, and Azure infrastructure templates.

**Tech Stack:** Python, FastAPI, React, PostgreSQL, Scikit-learn, TF-IDF, SVM, LangChain, Pinecone, BM25, Ollama, Cohere, Groq, Azure, Bicep.
